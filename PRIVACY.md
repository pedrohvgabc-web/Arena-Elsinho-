# Privacidade (LGPD)
Dados mínimos: nome, WhatsApp, reserva. Telefones mascarados no painel (revelar sob demanda). Disponibilidade pública não expõe dados pessoais. Pedidos de acesso/correção/exclusão via `/privacidade` → `privacy_requests`. Retenção sugerida: 12 meses (confirmar com o proprietário).
